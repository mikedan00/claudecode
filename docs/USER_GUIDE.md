# LLM 콘텐츠 출처·복사율 분석기 — 실행 방법과 사용 설명서

AI(LLM)가 만든 콘텐츠가 어떤 원본을 얼마나 가져다 썼는지 수치로 보여주고, 원본 출처를 찾아 목록으로 보여주는 웹 앱입니다.

---

## 1. 준비물

| 항목 | 내용 |
|---|---|
| Python | **3.10 이상** (`python --version` 으로 확인) |
| Git | 저장소를 내려받을 때 필요 |
| VS Code | 선택. 쓰려면 Python 확장(`ms-python.python`)을 설치 |
| 인터넷 연결 | 웹 검색으로 출처를 찾을 때 필요. 참조 파일 대조만 할 때는 없어도 됨 |

---

## 2. 설치

### 2-1. 저장소 내려받기

```bash
git clone https://github.com/mikedan00/claudecode.git
cd claudecode
```

### 2-2. 가상환경 만들기와 패키지 설치

**Windows (PowerShell)**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

> PowerShell에서 "스크립트를 실행할 수 없습니다" 오류가 나면 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 를 한 번 실행한 뒤 다시 시도하세요.

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2-3. (선택) 음성·영상 내용 분석 기능

음악·동영상 파일의 **말소리를 텍스트로 바꿔 분석**하려면 추가로 설치합니다. 설치하지 않으면 파일 정보(태그·메타데이터)만 확인합니다.

```bash
pip install faster-whisper
```

> 처음 사용할 때 음성 인식 모델(약 500MB)을 내려받습니다. CPU로 동작하므로 긴 파일은 시간이 걸립니다.

## 3. 실행

### 3-1. 터미널에서 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 나온 주소(보통 http://localhost:8501)로 접속하세요. 종료는 터미널에서 `Ctrl + C`.

### 3-2. VS Code에서 실행

1. VS Code에서 `claudecode` 폴더를 엽니다.
2. 오른쪽 아래 Python 인터프리터를 `.venv` 로 선택합니다. (`Ctrl+Shift+P` → *Python: Select Interpreter*)
3. 다음 중 하나로 실행합니다.
   - **디버그 실행:** `F5` → **Streamlit: app.py** 선택. 중단점(breakpoint)을 걸고 코드를 따라가며 볼 수 있습니다.
   - **작업(Task) 실행:** `Ctrl+Shift+P` → *Tasks: Run Task* → **Run Streamlit**

이 밖에 *Tasks: Run Task* 에는 **Install requirements**(패키지 설치), **Run tests**(테스트 실행)가 있습니다.

### 3-3. 검색 API 키 설정 (선택)

키가 없어도 무료인 **DuckDuckGo** 와 **위키백과**로 검색합니다. 더 정확한 검색이나 이미지 역검색이 필요하면 키를 설정합니다.

1. `.streamlit/secrets.toml.example` 을 복사해 `.streamlit/secrets.toml` 을 만듭니다.
2. 가진 키만 채웁니다.

```toml
SERPAPI_KEY = "여기에 키"          # Google 검색 + 이미지 역검색(Google Lens)
GOOGLE_API_KEY = ""                # Google 맞춤 검색(CSE) — CSE_ID와 함께
GOOGLE_CSE_ID = ""
TAVILY_API_KEY = ""                # Tavily 검색
```

- 여러 개를 넣으면 **SerpAPI → Google CSE → Tavily → DuckDuckGo** 순서로 하나만 사용합니다.
- 환경변수로 설정해도 됩니다. (예: `export SERPAPI_KEY=...`)
- `secrets.toml` 은 `.gitignore` 에 들어 있어 GitHub에 올라가지 않습니다.

| 서비스 | 발급처 |
|---|---|
| SerpAPI | https://serpapi.com |
| Google CSE | https://programmablesearchengine.google.com (+ Google Cloud에서 API 키 발급) |
| Tavily | https://tavily.com |

## 5. 사용 방법

### 5-1. 파일 분석

1. **📁 파일 업로드** 탭에서 파일을 올립니다. (파일당 최대 200MB)
2. **파일 분석** 버튼을 누릅니다.

| 파일 종류 | 확장자 | 분석 내용 |
|---|---|---|
| 텍스트 | txt, md, csv, json, html, rtf | 본문 → 출처 검색·대조, AI 문체 분석 |
| 문서 | docx, pdf, pptx | 본문(표·슬라이드 노트 포함) 추출 후 위와 같음 |
| 이미지 | png, jpg, webp, gif, bmp, tiff | 생성 AI 흔적(메타데이터) 확인, 참조 이미지와 유사도 비교 |
| 음악 | mp3, wav, flac, m4a, ogg, aac | 태그·생성 AI 흔적 확인, (faster-whisper 설치 시) 가사·음성 분석 |
| 동영상 | mp4, mov, mkv, webm, avi | 위와 같음 |

> 스캔한 PDF(글자가 이미지인 PDF)는 텍스트를 뽑을 수 없어 분석되지 않습니다.

### 5-2. URL 분석

1. **🔗 URL** 탭에 주소를 붙여넣고 **URL 분석** 을 누릅니다.

| URL 종류 | 처리 방식 |
|---|---|
| 뉴스·블로그 | 광고·메뉴를 빼고 본문만 추출 |
| YouTube 영상·쇼츠 | 자막(한국어→영어→일본어 순)을 가져와 분석. 자막이 없으면 제목만 분석 |
| SNS 게시글 | 공개된 미리보기 텍스트만 분석(로그인이 필요한 글은 내용이 거의 없을 수 있음) |
| 이미지 주소 | 이미지 분석 + `SERPAPI_KEY` 가 있으면 웹에서 같은/비슷한 이미지 역검색 |
| PDF·문서 주소 | 파일을 내려받아 파일 분석과 같게 처리 |

### 5-3. 텍스트 붙여넣기

**📝 텍스트 붙여넣기** 탭에 글을 붙여넣고 **텍스트 분석** 을 누릅니다. ChatGPT·Claude 등의 답변을 바로 검사할 때 편합니다.

## 6. 결과 읽는 법

### 6-1. 점수 5개

| 점수 | 뜻 | 계산 방법 | 해석 |
|---|---|---|---|
| **LLM 재활용 지수** | 종합 점수 | `0.6 × max(축자 복사율, 학습데이터 추정 중복률) + 0.4 × AI 생성 가능성` | 높을수록 원본을 많이 가져다 쓴 AI 생성물일 가능성이 큼 |
| **축자 복사율** | 원문을 그대로 옮긴 비율 | 연속된 5단어 묶음 중 찾은 출처에도 똑같이 있는 비율 | 10% 이상이면 일부 복사, 30% 이상이면 상당 부분 복사로 볼 만함 |
| **학습데이터 추정 중복률** | 공개 학습 데이터와 겹치는 비율 | 공개 웹·위키백과 출처에서만 센 축자 복사율 | LLM이 학습한 글을 거의 그대로 내놓았을 가능성 |
| **AI 생성 가능성** | AI가 썼을 가능성 | 텍스트: 문체 통계 / 이미지·미디어: 생성 도구 흔적 | 아래 6-2 참고 |
| **독창성** | 100 − 축자 복사율 | | 높을수록 기존 글과 겹치지 않음 |

> 점수 옆 **?** 아이콘에 마우스를 올리면 설명이 나옵니다. 위 해석 기준은 참고용 경험치이며 절대 기준이 아닙니다.

### 6-2. AI 생성 가능성 근거

**AI 생성 가능성 근거** 를 펼치면 판단 이유가 나옵니다.

**텍스트** — 5가지 신호를 가중 합산합니다. (40단어·3문장 미만이면 "판단 불가")

| 신호 | 의미 | 비중 |
|---|---|---|
| 문장 길이 균일성 | AI 글은 문장 길이가 고르게 비슷한 경향 | 30% |
| LLM 상투어 빈도 | "결론적으로", "다양한", "it's important to note", "delve" 같은 표현 | 30% |
| 어휘 다양성 부족 | 같은 단어를 반복하는 정도 | 15% |
| 문장 시작어 반복 | 문장이 같은 단어로 자주 시작하는 정도 | 15% |
| 목록형 구조 | 글머리표·번호 목록 비율 | 10% |

**이미지·음악·동영상**

| 결과 | 조건 |
|---|---|
| 95% | C2PA 콘텐츠 자격증명, IPTC "AI 생성" 표시, Stable Diffusion 프롬프트, Midjourney·DALL·E·Firefly·Suno·Sora 등 도구 이름이 파일 안에서 발견됨 |
| 20% | 카메라 제조사·모델 정보(EXIF)가 있음 → 실제 촬영 가능성 |
| 50% | 메타데이터가 지워져 판단 근거가 없음(중립값) |

### 6-3. 역추적된 원본 출처

찾은 출처를 복사율이 높은 순서로 보여줍니다.

| 열 | 설명 |
|---|---|
| 출처 / URL | 원본 후보의 제목과 주소(클릭하면 열림) |
| 분류 | 그 출처가 속한 것으로 알려진 학습 데이터 종류 (Wikipedia, GitHub, arXiv, StackExchange, Reddit, 블로그, 나무위키, 공개 웹 등) |
| 검색경로 | 어떻게 찾았는지 (SerpAPI, DuckDuckGo, Wikipedia, 참조 파일 등) |
| 축자 복사율 | 이 출처 하나와 그대로 겹치는 비율 |
| 어휘 유사도 | 사용한 단어 분포가 얼마나 비슷한지. 문장을 바꿔 쓴(의역) 경우 복사율은 낮아도 이 값은 높게 나옴 |
| 일치 문장 | 출처의 문장과 50% 이상 겹치는 문장 수 |

- 출처는 **축자 복사율 3% 이상, 어휘 유사도 60% 이상, 일치 문장 1개 이상** 중 하나라도 해당해야 목록에 나옵니다.
- 웹 검색 결과는 최대 12개 페이지까지 내려받아 비교합니다.
- **일치 구간** 을 펼치면 분석 대상 문장과 출처 문장을 나란히 볼 수 있습니다.

## 7. 활용 예시

**① AI가 쓴 블로그 글이 위키백과를 베꼈는지 확인**
→ 📝 탭에 글을 붙여넣고 분석 → 분류가 "Wikipedia"인 출처의 축자 복사율과 일치 구간 확인

**② 과제 보고서가 특정 자료를 베꼈는지 확인**
→ 사이드바 **참조 원본** 에 의심 자료(PDF·워드)를 올림 → 📁 탭에 보고서를 올려 분석 → 검색경로가 "참조 파일"인 행 확인

**③ 이미지가 AI로 만든 것인지 확인**
→ 원본 파일 그대로(메신저로 받은 사진은 메타데이터가 지워졌을 수 있음) 📁 탭에 올림 → AI 생성 가능성 근거에서 발견된 표식 확인

**④ 유튜브 쇼츠 대본이 기존 글을 가져다 썼는지 확인**
→ 🔗 탭에 쇼츠 주소 입력 → 자막을 가져왔다는 안내가 뜨는지 확인한 뒤 출처 목록 확인

## 8. 인터넷에 배포하기 (Streamlit Community Cloud, 무료)

1. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
2. **Create app** → *Deploy a public app from GitHub* 를 선택합니다.
3. 다음과 같이 입력합니다.
   - Repository: `mikedan00/claudecode`
   - Branch: `main`
   - Main file path: `app.py`
4. (선택) **Advanced settings → Secrets** 에 3-3의 `secrets.toml` 내용을 붙여넣습니다.
5. **Deploy** 를 누르면 몇 분 뒤 `https://<앱이름>.streamlit.app` 주소가 생깁니다.

> 무료 배포 환경은 메모리가 작아 `faster-whisper` 는 권장하지 않습니다. `main` 에 새 코드를 올리면 자동으로 다시 배포됩니다.

## 9. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| `streamlit: command not found` | 가상환경이 켜져 있지 않습니다. 2-2의 activate 명령을 다시 실행하거나 `python -m streamlit run app.py` 로 실행하세요 |
| `ModuleNotFoundError` | `pip install -r requirements.txt` 를 다시 실행하세요 |
| `TypeError: unsupported operand type(s) for \|` | Python 3.9 이하입니다. 3.10 이상을 설치하세요 |
| "웹 검색 실패" 경고 | 인터넷 연결·방화벽을 확인하세요. DuckDuckGo는 요청이 많으면 일시 차단할 수 있으니 잠시 후 다시 시도하거나 API 키를 설정하세요 |
| 출처가 0건 | 원본이 검색 엔진에 없거나, 의역이 심해 일치하는 문장이 없는 경우입니다. 검색 질의 수를 늘리거나 의심 원본을 참조 파일로 올려보세요 |
| AI 생성 가능성 "판단 불가" | 글이 짧습니다(40단어·3문장 이상 필요) |
| YouTube "자막을 가져오지 못했습니다" | 자막이 없는 영상이거나 YouTube가 요청을 막은 경우입니다. 제목만 분석됩니다 |
| PDF 분석 결과가 비어 있음 | 스캔본 PDF입니다. 텍스트가 들어 있는 PDF로 바꿔 올리세요 |
| 이미지 역검색 안내만 나옴 | 업로드한 이미지는 주소가 없어 역검색할 수 없습니다. 이미지 URL을 🔗 탭에 넣고 `SERPAPI_KEY` 를 설정하세요 |
| 분석이 오래 걸림 | 웹 페이지를 최대 12개 내려받아 비교하기 때문입니다. 검색 질의 수를 줄이세요 |

## 10. 꼭 알아둘 한계

- **학습데이터 추정 중복률은 확정값이 아닙니다.** 상용 LLM의 실제 학습 데이터 목록은 공개되지 않습니다. 이 값은 "학습 데이터에 들어 있을 가능성이 높은 공개 출처"와 겹치는 정도입니다.
- **AI 생성 가능성은 학습된 판별 모델이 아닌 규칙 기반 점수입니다.** 짧은 글, 사람이 다듬은 AI 글, 격식체로 쓴 사람 글에서 틀릴 수 있습니다.
- **의역은 축자 복사율로 잡히지 않습니다.** 어휘 유사도를 함께 보세요.
- **메타데이터가 지워진 이미지·음원**(캡처, 메신저 전송, SNS 재업로드)은 생성 여부를 판단하기 어렵습니다.
- 위 이유로 **법적 판단이나 징계의 유일한 근거로 사용하지 마세요.** 결과는 사람이 원본을 직접 확인할 출발점으로 쓰는 것이 좋습니다.
- 분석한 텍스트 일부가 검색 질의로 외부 검색 서비스에 전송됩니다. 민감한 문서는 웹 검색을 끄고 참조 파일 대조만 사용하세요.
