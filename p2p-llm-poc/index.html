개요

지금 연결된 노드와 자원, 큐 상태, PoC 진행률을 한눈에 봅니다. 기준 환경은 Windows 11 노트북 + RTX 4070 Laptop 8GB입니다.

기준 환경 제약

브라우저는 VRAM 용량을 알려주지 않으므로 노드 프로필의 값을 씁니다. WebGPU 버퍼 한도와 실측 대역폭은 노드 화면에서 측정합니다.

노드 연결

연결 경로는 두 가지입니다. 실행 환경에서 쓸 수 있는 경로가 자동으로 켜집니다.

Sites room 중계

Sites에 게시된 페이지를 연 사람끼리 자동으로 연결됩니다. 메시지는 Sites 서버를 거치므로 측정되는 RTT에 중계 지연이 포함됩니다. 작업을 보내려면 아티팩트 공유 설정에서 참여자에게 Contributor 이상 권한이 있어야 합니다.

WebRTC DataChannel

Sites 페이지 안에서는 WebRTC가 차단됩니다. 저장소의 HTML 파일을 Chrome이나 Edge에서 직접 열면 사용할 수 있습니다. 시그널링은 아래에서 코드를 복사해 상대에게 전달하는 방식입니다(메신저 등으로 전달).

단계별 PoC 진행 현황

상태와 체크 항목, 메모를 바꾸면 바로 저장됩니다. 공유 DB를 쓰는 경우 참여자 모두가 같은 현황을 봅니다.

SwarmLLM과 현재 설계의 차이

항목별로 두 설계를 비교하고 PoC에 주는 영향을 적어 둡니다. 칸을 고치면 저장됩니다.

SwarmLLM 열의 처음 내용은 일반적인 스웜형 분산 추론 설계(설치형 GPU 서버 노드, DHT 피어 탐색, 블록 단위 파이프라인)를 가정해 채운 초안입니다. 실제 SwarmLLM 문서와 대조해 고쳐 주세요.
