# Browser Swarm PoC

설치 없이 브라우저 탭 하나를 노드 하나로 삼아 P2P 분산 LLM 추론을 실험하고 관리하는 단일 파일 웹앱입니다. HELIX와 연동하지 않는 독립 도구입니다.

- `index.html`: 앱 전체 (Sites에 게시하는 원본이자 로컬 실행 파일)
- `GUIDE.md`: 실행 방법과 사용 설명서

## 실행 방식

| 실행 위치 | 노드 연결 | 저장 | 실추론 (WebLLM) |
|---|---|---|---|
| Sites (claude.ai 아티팩트) | room 중계 (자동) | 공유 DB | 가중치 다운로드가 차단될 가능성 높음 |
| 로컬 (`index.html`을 Chrome/Edge로 직접 열기) | WebRTC DataChannel (수동 시그널링) | 브라우저 localStorage | 가능 |

Sites 페이지 안에서는 WebRTC가 차단되므로 직접 P2P 측정은 로컬 실행으로 합니다. 두 환경의 데이터는 실행 기록 화면의 JSON 내보내기/가져오기로 옮깁니다.

## 기준 환경
Windows 11 노트북, RTX 4070 Laptop 8GB. 브라우저가 쓸 수 있는 VRAM은 약 5.6GB로 가정합니다(프로필에서 조정).

## 추론 모델
- 노드 연결, RTT, 핑 손실, WebGPU 감지, GPU 복사 대역폭은 실측합니다.
- 추론은 기본적으로 시뮬레이터입니다. 디코딩 tok/s ≈ 유효 대역폭 ÷ 가중치 크기, 프리필은 연산량 기준입니다.
- 레이어 분할은 코디네이터 중심 별형 토폴로지를 가정하고, 토큰마다 단계별 실측 RTT를 더합니다.
- WebLLM을 불러온 노드는 같은 모델 요청을 실제로 실행합니다.

## 설계 메모
SwarmLLM 비교표의 SwarmLLM 열은 일반적인 스웜형 분산 추론 설계를 가정해 채운 초안입니다. 실제 문서와 대조해 고쳐야 합니다.
